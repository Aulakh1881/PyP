The AI proposes. Code decides.

Pyp’s AI only ever suggests. Plain, testable rules decide what can run on its own, and they re-check PayPal right before anything happens.

1

A buyer’s message is information, never an order

If a buyer writes “refund me now”, Pyp reads it as context. It can’t be talked into moving money.

2

Small refunds run on Auto, with an undo

Within your limit (say $25), refunds go through after a 60-second window you can cancel. Anything bigger waits for you.

3

Big or sensitive steps always wait for you

Dispute evidence is never Auto. Pyp drafts it, you review and edit, you press send.

4

Every step is timestamped and logged

Trigger, what Pyp read, what the AI proposed, which checks passed, which rule applied. Flip any card to see it.

Get the Chrome extension

Pyp isn’t on the Chrome Web Store yet. Install the preview in a minute:

  1. 1
    Get the code from GitHub (Code → Download ZIP) and unzip it.
  2. 2
    Open chrome://extensions and switch on Developer mode (top right).
  3. 3
    Click Load unpacked and choose the prototype/extension folder.
  4. 4
    Go to paypal.com. Pyp appears in the bottom-right corner. Click the Pyp icon in Chrome’s toolbar to see what’s waiting on you or open the web app.
