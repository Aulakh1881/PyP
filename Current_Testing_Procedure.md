To test log in:  
Run npm install. This will install the supabase dependencies.  
Create .env.local. Add the Supabase URL and publishable key (I will send these to you).  

Have terminal 1 and run: npm run dev  
Have terminal 2 and run: py -m http.server 8080 --directory prototype/website  
Open http://localhost:8080  
Click the blue "Sign in" button  
Click "Sign up", choose email and password you want, check your mail to accept the verification email (you must do this), then sign in through the "Sign in" tab.
